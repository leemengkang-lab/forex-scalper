# forex-scalper

forex-scalper — multi-timeframe / multi-pair scalping bot (OANDA v20). Replaces the earlier breakout bot. See docs/superpowers/plans/ for the build plan and docs/runbook.md for operations.

## Quick start

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -e ".[dev]"
pytest
```
